# โน้ตแต่งเพลง 🎵

เว็บแอปช่วยเขียน prompt สำหรับแต่งเพลง เลือกแนวเพลง อารมณ์ เครื่องดนตรี จังหวะ และรูปแบบการสัมผัส แล้วรับ prompt พร้อมใช้

## ความสามารถ
- แนวเพลง 14 แนว พร้อมค่าที่แนะนำสำหรับแต่ละแนว
- เครื่องดนตรีทั้งสากลและไทย (พิณ แคน ระนาด ซอ ขลุ่ย)
- การสัมผัส 9 แบบ พร้อมคำอธิบายและตัวอย่าง
- ผลลัพธ์ 2 แบบ: prompt เขียนเนื้อเพลง และแท็กสไตล์สำหรับ Suno/Udio
- ปุ่มสุ่มไอเดีย และปุ่มคัดลอก

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## เปิดเป็นเว็บด้วย GitHub Pages
Settings → Pages → Source: Deploy from a branch → เลือก `main` / `root` → Save
